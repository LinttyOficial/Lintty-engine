# 03 — Motor Roslyn (LOCKED)

O motor é o componente que carrega a Solution C# entregue pela agência, extrai um grafo semântico via Roslyn, aplica as regras determinísticas e identifica candidatos para análise semântica via LLM. Tudo dentro de uma sandbox efêmera que é destruída ao fim.

## 1. Ambiente de Execução

### Container

| Item | Valor |
|------|-------|
| Imagem base | `mcr.microsoft.com/dotnet/sdk:9.0` |
| Sistema | Linux (não Windows) |
| Orquestrador | Console App C# usando `Microsoft.CodeAnalysis.MSBuild` |
| .NET targets suportados | 6, 7, 8, 9 (modernos) |
| .NET Framework 4.x | **NÃO suportado no MVP**; entra em v1.1 com imagem Windows + VS Build Tools |

### Recursos por scan (Cloud Run Job)

| Tier de LoC | vCPU | RAM | Timeout |
|-------------|------|-----|---------|
| ≤200k LoC | 4 | 16 GB | 45 min |
| 200k–1M LoC | 8 | 32 GB | 120 min |
| >1M LoC | 16 | 64 GB | 240 min (enterprise quote) |

16 GB é o "sweet spot" para o MSBuildWorkspace não entrar em swap durante o carregamento de grafos de símbolos grandes.

### NuGet privado

Suportado via secret do GitHub App. Fluxo:
1. Contratante registra credencial de feed privado no `lintty.yml` (referência a um GitHub Actions secret no repo do contratante).
2. Worker do Lintty lê o secret on-demand via API do GitHub durante a fase de `dotnet restore`.
3. Após restore, secret é zerado da memória do worker.
4. Cache de pacotes é descartado junto com a sandbox.

NuGet **público** passa pelo proxy interno via Artifact Registry no modo "remote repository" — não há egress externo para `nuget.org`.

## 2. Bootstrap obrigatório

Duas chamadas que, se omitidas, causam bugs silenciosos críticos:

```csharp
// Localiza MSBuild antes de criar o workspace
MSBuildLocator.RegisterDefaults();

var workspace = MSBuildWorkspace.Create();

// CRÍTICO: subscreve eventos de falha; sem isso, OpenSolutionAsync engole erros
// silenciosamente e retorna solution parcial — analyzers veem símbolos faltando
// e geram laudo aprovando código que tinha problemas.
workspace.WorkspaceFailed += (sender, args) => {
    if (args.Diagnostic.Kind == WorkspaceDiagnosticKind.Failure) {
        throw new CompilationLoadException(args.Diagnostic.Message);
    }
};
```

**Política Fail-Fast:** qualquer falha de carga é abort do scan. Não há "auditoria parcial" no Lintty. Crédito é estornado se falhou aqui (build não chegou nem a rodar).

## 3. Pipeline canônico (ordem)

```
1. Git shallow clone (--depth=1, commit SHA fixo)
2. Build Gate
   ├─ dotnet restore (com secret de feed privado se configurado)
   └─ dotnet build --no-incremental
   FALHA → status=failed_compile, crédito ESTORNADO, FIM.
3. MSBuildLocator.RegisterDefaults()
4. MSBuildWorkspace.OpenSolutionAsync (com WorkspaceFailed vigilante)
5. Filtro de código gerado:
   ├─ Excluir SyntaxTree.IsGeneratedCode
   ├─ Excluir arquivos com header <auto-generated>
   └─ Excluir paths obj/**, **/Generated/**
6. Layer tagging: lintty.yml > convention; FAIL-FAST se nem um nem outro classifica
7. DAG de projetos → análise paralela respeitando dependências topológicas
8. Deterministic Rule Engine: aplica LNTY-001/002/003/006/007/008
9. Semantic Slicing: identifica candidatos para LNTY-004/005
10. @lintty-ignore parsing: motor extrai (file, line, rule, justification, author)
11. Emissão do output JSON
12. AuditEvent registrado (hash-chained)
13. Sandbox teardown:
    ├─ Diretório de checkout deletado
    ├─ Cache NuGet apagado
    └─ Secrets zerados da memória
14. Mensagem para Pub/Sub: scan.completed (ou scan.failed)
```

## 4. Algoritmos por regra

### LNTY-001 — Domain Layer Isolation

```csharp
// Pass 1: ProjectReferences
foreach (var project in solution.Projects.Where(p => p.LayerTag == "domain")) {
    foreach (var refProj in project.AllProjectReferences) {
        var refTag = ClassifyLayer(refProj);
        if (refTag is "infrastructure" or "presentation") {
            EmitViolation("LNTY-001", project, refProj);
        }
    }
}

// Pass 2: Symbol-level (pega o que NuGet bridge esconderia)
foreach (var doc in domainDocuments) {
    var semanticModel = await doc.GetSemanticModelAsync();
    var root = await doc.GetSyntaxRootAsync();
    foreach (var node in root.DescendantNodes().OfType<IdentifierNameSyntax>()) {
        var symbol = semanticModel.GetSymbolInfo(node).Symbol;
        if (symbol == null) continue;
        var assemblyTag = ClassifyAssembly(symbol.ContainingAssembly);
        if (assemblyTag is "infrastructure") {
            EmitViolation("LNTY-001", node, symbol);
        }
    }
}
```

### LNTY-002 — Persistence Contamination

```csharp
// Pass 1: Type references to forbidden namespaces
var forbiddenNamespaces = new[] {
    "Microsoft.EntityFrameworkCore",
    "MongoDB.Driver",
    "Dapper",
    "System.Data",
    "Npgsql",
    "Microsoft.Data.SqlClient"
};

foreach (var doc in domainDocuments) {
    var semanticModel = await doc.GetSemanticModelAsync();
    var root = await doc.GetSyntaxRootAsync();
    foreach (var node in root.DescendantNodes().OfType<IdentifierNameSyntax>()) {
        var symbol = semanticModel.GetSymbolInfo(node).Symbol;
        if (symbol?.ContainingNamespace?.ToString() is string ns
            && forbiddenNamespaces.Any(f => ns.StartsWith(f))) {
            EmitViolation("LNTY-002", node, ns);
        }
    }
}

// Pass 2: SQL literals (incluindo constant folding)
var sqlPattern = new Regex(
    @"^\s*(SELECT|INSERT|UPDATE|DELETE|MERGE)\s+.+(\s+FROM\s+|\s+INTO\s+)",
    RegexOptions.IgnoreCase
);

foreach (var doc in domainDocuments) {
    var semanticModel = await doc.GetSemanticModelAsync();
    var root = await doc.GetSyntaxRootAsync();
    
    // Inclui literais E expressões que constant-folding resolve
    var nodes = root.DescendantNodes()
        .Where(n => n is LiteralExpressionSyntax 
                 || n is BinaryExpressionSyntax 
                 || n is InterpolatedStringExpressionSyntax);

    foreach (var node in nodes) {
        var constValue = semanticModel.GetConstantValue(node);
        if (constValue.HasValue && constValue.Value is string s 
            && sqlPattern.IsMatch(s)) {
            EmitViolation("LNTY-002", node, s);
        }
    }
}
```

### LNTY-003 — Forbidden Instantiation

```csharp
foreach (var doc in applicationOrPresentationDocs) {
    var semanticModel = await doc.GetSemanticModelAsync();
    var root = await doc.GetSyntaxRootAsync();
    
    foreach (var newExpr in root.DescendantNodes().OfType<ObjectCreationExpressionSyntax>()) {
        var typeInfo = semanticModel.GetTypeInfo(newExpr.Type);
        var typeSymbol = typeInfo.Type as INamedTypeSymbol;
        if (typeSymbol == null) continue;
        
        // Exceções: records, value types, system types
        if (typeSymbol.IsRecord || typeSymbol.IsValueType) continue;
        if (typeSymbol.ContainingNamespace?.ToString().StartsWith("System.") == true) continue;
        if (typeSymbol.AllInterfaces.Any(i => i.Name == "Exception")) continue;
        
        var infraClassified = ClassifyAssembly(typeSymbol.ContainingAssembly) == "infrastructure";
        var hasInterface = solution.HasInterface($"I{typeSymbol.Name}", inLayer: "domain");
        
        if (infraClassified || hasInterface) {
            EmitViolation("LNTY-003", newExpr, typeSymbol);
        }
    }
}
```

### LNTY-006 — Ubiquitous Language Leak (blacklist)

```csharp
var bannedExact = new Regex(@"^(Data|Info|Temp|Stuff|Thing|Misc|Generic)\d*$");
var bannedSuffix = new Regex(@"(Manager|Helper|Util|Utils|Utility)$");

foreach (var doc in domainDocuments) {
    var root = await doc.GetSyntaxRootAsync();
    var declarations = root.DescendantNodes().OfType<MemberDeclarationSyntax>()
        .Concat(root.DescendantNodes().OfType<NamespaceDeclarationSyntax>().Cast<MemberDeclarationSyntax>());
    
    foreach (var decl in declarations) {
        var name = ExtractName(decl);
        if (bannedExact.IsMatch(name) || bannedSuffix.IsMatch(name)) {
            EmitViolation("LNTY-006", decl, name);
        }
    }
}
```

### LNTY-007 — Dependency Cycles (dois grafos)

// Grafo 1: Projects
var projectGraph = BuildGraph(solution.Projects, p => p.AllProjectReferences);

### LNTY-008 — Ports at Boundaries

```csharp
foreach (var infraType in solution.Types.Where(t => 
    t.DeclaredAccessibility == Accessibility.Public 
    && ClassifyAssembly(t.ContainingAssembly) == "infrastructure")) {
    
    var refs = await SymbolFinder.FindReferencesAsync(infraType, solution);
    var crossAssemblyRefs = refs.SelectMany(r => r.Locations)
        .Where(loc => loc.Document.Project.AssemblyName != infraType.ContainingAssembly.Name);
    
    if (!crossAssemblyRefs.Any()) continue;  // Não cruza assembly, ok
    
    var hasPortInterface = solution.HasInterface($"I{infraType.Name}", 
        inLayer: ["domain", "domain.abstractions"]);
    
    if (!hasPortInterface) {
        EmitViolation("LNTY-008", infraType, crossAssemblyRefs);
    }
}
```

### LNTY-009 — Method Exceeds Analyzability

Aplicado **após** o semantic slicing. Se o slice serializado para o prompt LLM excede 8.000 tokens (medido via tokenizer da Anthropic), emite violação **sem chamar a LLM**:

```csharp
var slice = BuildSlice(method, contextDepth: 50);
var tokenCount = AnthropicTokenizer.Count(slice);
if (tokenCount > 8000) {
    EmitViolation("LNTY-009", method, evidence: new {
        token_count = tokenCount,
        loc_count = method.Body.GetText().Lines.Count,
        method_signature = method.ToFullSignature()
    });
    return;  // Não envia para LLM
}
```

## 5. Semantic Slicing — contrato factual

### Princípio

O motor entrega **fatos frios**, não interpretações. A IA interpreta. Isso elimina alucinação recursiva (motor "explicando" código → IA acreditando na explicação).

### Conteúdo do slice

Para cada candidato (método marcado pelos pré-filtros das regras LLM):

```json
{
  "rule_id": "LNTY-004",
  "location": {
    "file": "MyCompany.Orders.Persistence/OrderRepository.cs",
    "line_start": 45,
    "line_end": 78
  },
  "code_slice": "<corpo do método + 50 LoC de contexto acima/abaixo>",
  "context_summary": {
    "containing_class": "MyCompany.Orders.Persistence.OrderRepository",
    "implements": ["MyCompany.Orders.Domain.IOrderRepository"],
    "cyclomatic_complexity": 7,
    "invoked_symbols": [
      "MyCompany.Orders.Domain.Order.CalculateDiscount()",
      "Microsoft.EntityFrameworkCore.DbSet<T>.Add()",
      "Microsoft.EntityFrameworkCore.DbContext.SaveChangesAsync()"
    ],
    "invoked_from": [
      "MyCompany.Orders.Application.PlaceOrderHandler.Handle()"
    ]
  },
  "fingerprint": "sha256:abc123..."
}
```

### Budget

- **Target:** 6.000 tokens (deixa 2K margem para system prompt + few-shots + output JSON)
- **Hard cap:** 8.000 tokens
- **Acima de 8K:** dispara LNTY-009, não vai para LLM

### Fingerprint

```
fingerprint = sha256(rule_id || code_slice_normalized || canon_version)
```

Usado para:
- Cache de inferência (mesmo slice + mesma regra + mesma versão = reusa resultado)
- Deduplicação no relatório final

## 6. Parsing de `@lintty-ignore`

Responsabilidade do motor (não do Control Plane). Motor extrai os fatos; Control Plane aplica políticas (hard locks, cap de 10%, grade penalty).

### Sintaxe aceita

```csharp
// @lintty-ignore: LNTY-004 reason="Razão clara explicando porque é falso positivo"

```

## 8. Paralelização

### Estratégia

Roslyn é mono-thread por compilation. Paralelização viável: **por projeto**.

```
1. Construir DAG de projetos (topological order via ProjectReference)
2. Identificar grupos independentes (mesma "altura" no DAG)
3. Cada grupo é analisado em paralelo, respeitando que dependências já estão prontas
4. Combinar resultados antes de aplicar regras de grafo (LNTY-007, LNTY-008)
```

### Exemplo

Solution com 8 projetos:
```
A (Domain) ←──┬── B (Application)
              │      ↑
C (Domain.Abs)┘      │
                     │
D (Infrastructure) ──┘
              ↑
E (Persistence) ←─── F (Infrastructure.Email)
              ↑
G (WebApi) ←──┴── H (WebUi)
```

Análise:
- Nível 1 (paralelo): A, C, F
- Nível 2 (paralelo): B, D, E (após nível 1)
- Nível 3 (paralelo): G, H

## 9. Cache incremental (V1, NÃO MVP)

No MVP, todo scan é full. No V1:

- Fingerprint por arquivo: `sha256(file_content || canon_version)`
- Se arquivo não mudou desde último scan do mesmo repo, **reusa** as violações e `ai_candidates` daquele arquivo.
- Cache invalidado quando: canon version muda, conteúdo do arquivo muda, layer tagging muda.
- Economia esperada: 60-80% em re-scans de Milestone.
